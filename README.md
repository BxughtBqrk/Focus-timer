## ⚡ Overview
FocusTimer is a premium, open-source productivity timer designed for absolute focus. It features a stunning transparent glassmorphism UI, advanced distraction blocking algorithms, and hardcore productivity locks to ensure you stay entirely locked into your workflow.

## ✨ Features
* **Premium Glassmorphism UI:** A borderless, hardware-accelerated translucent design with fluid micro-animations and cyber-gradients.
* **👻 Ghost Mode:** Completely melts the application into your desktop wallpaper, turning the timer into an ambient HUD that doesn't disrupt your visual workspace.
* **🛡️ Active Distraction Blocker:** Behind-the-scenes engine that actively hunts down and forcefully minimizes or kills user-defined distracting apps (like Discord) and browser tabs (like YouTube).
* **🔒 Iron Will Mode:** A hardcore productivity lock-in system. When enabled, the pause button, settings menu, and window resize controls are entirely disabled until the timer hits zero. You literally cannot stop.
* **📌 Always On Top:** Pin the timer over all other windows so it never gets lost.

## 🚀 Getting Started

### Download (No installation required)
1. Go to the [Releases](../../releases/latest) page.
2. Download the `FocusTimer.exe` standalone file.
3. Double click to run!

### For Developers (Build from source)
This project is built using C#, .NET 10, and Avalonia UI utilizing the MVVM architecture.

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/FocusTimer.git

# Navigate to the project directory
cd FocusTimer

# Run the application
dotnet run
```

## 🛠️ Technology Stack
* **Language:** C# 12
* **Framework:** .NET 10.0
* **UI Framework:** Avalonia UI 11 / Desktop
* **Architecture:** MVVM (CommunityToolkit.Mvvm)
